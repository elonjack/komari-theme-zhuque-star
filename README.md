# Komari · 朱雀星

一个从零编写、零运行时依赖的 Komari 非官方《仙逆》同人主题。v0.7.2「宗门万象」以银白王林动态首屏为视觉母体，不使用节点卡片墙，而以“昼夜朱雀星 → 国家宗门 → 宗门阵眼长卷”呈现完整监控信息。

## v0.7.0 范围

v0.7.1 将朱雀星球上的坐标标记精简为纯国旗图标，移除装饰性的“朱雀”方印与遮挡地表的宗门文字条；宗门名、国家和在线数仍保留在右侧坐标录与悬停说明中。v0.7.2 修复 Release ZIP 条目带 `./` 前缀导致 Komari 远程导入误报缺少 `komari-theme.json` 的问题，并写入仓库更新地址。

- 原人物 4K 本地图片驱动的 WebGL 动态首屏：三层发丝分别摆动、衣袍呼吸、眼部灵光、星尘与雾气，并可切换静风、灵风、狂风；低动态偏好或 WebGL 不可用时自动静态回退。
- 真实材质朱雀星：自行编写 WebGL 球体着色器，混合 4K 白天地表、夜间灯光、地形明暗与水面高光，并加入昼夜分界、菲涅耳大气层和动态光照；不引入 Three.js 或远程运行库。
- 真实国家经纬度、国旗与宗门名称随星体自转，支持拖动、点击筛选、离屏暂停与低动态偏好；WebGL 或纹理不可用时自动切换本地静态星体。
- 全站字韵可选“颜楷风、行书风、宋韵风、现代易读”；只调用本机字体并设置完整回退，不联网下载字体。
- 六套独立宗门场景与印记：恒岳派、大罗剑宗、雨之仙界、战神殿、云天宗采用明亮仙气视觉；炼魂宗采用幽暗魂火视觉，不再共用同一套暗色图片。
- 首页星域总览与全宽节点谱：CPU、内存、硬盘、上下行、累计流量、在线时间、价格、到期与 Ping。
- 节点独立国旗铭牌：兼容 `HK`、`Hong Kong`、`香港` 与 `🇭🇰` 等地区写法；宗门标题、节点行、详情页与流量页均可直接辨认国家。
- 可配置国家宗门映射，例如 `CN=恒岳派;JP=战神殿`；真实国家归属与 Komari 原分组不会被修改。
- 节点观测页：CPU 型号/核心、GPU、系统/架构/内核/虚拟化、内存、Swap、硬盘、负载、温度、进程、TCP/UDP、实时与累计网络、今日流量、24h 峰值、限额口径、最近上报、标签、账期/到期/续费、Ping 最新值/丢包/P50/P99/标准差及资源、网络、进程/连接、Ping 历史曲线。
- 可选网络身份模块：在主题设置显式开启后才保留并显示 IPv4/IPv6、原生/广播/任播分类、位置、注册地、ASN、运营商、网络类型、网段/域名、可用时的信誉数据与全球延迟；默认关闭。
- 星路页：实时带宽、累计流量、限额占用与节点排行。
- 山河册：资产、服务商、币种、续费周期和到期提醒。
- `/api/rpc2` 与旧版 REST 兼容回退，支持 `temp_key` 分享链接。
- 所有素材、样式和代码随主题本地打包，不加载第三方 CDN。

## 安全边界

主题只读取 Komari 公开监控接口，不包含终端或命令执行功能；始终丢弃 Token、密码和私有备注。节点 IP 默认不会进入页面数据，只有将 `show_network_identity` 显式设为 `true` 时才用于本机 Komari 的可选 IP 信息插件；不会发给第三方站点。主题设置由 `/api/public` 公开，禁止写入密钥和私密 URL。
